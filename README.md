# Kraken-release

The public release channel for [Kraken](https://github.com/spikediegel-prog/Kraken) — the parallel edition of Pulpo: many arms, one head.

This repo holds releases only. The source code is developed in the private Kraken repository and is not published here. Each release is a versioned directory under `releases/` (for example `releases/v0.1.0/`), containing the built artifacts for that version plus `SHA256SUMS` and a `RELEASE` manifest naming the version.

Releases are published here automatically when a version is tagged in the private repo. Nothing else is published to this repo.

No license has been issued yet — a license is picked before the first public release.
